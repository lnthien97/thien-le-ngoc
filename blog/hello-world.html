Đây là bài viết mẫu. Để viết bài mới, copy file này, đổi tên (ví dụ ten-bai-viet.html), sửa nội dung, rồi thêm link vào blog/index.html và mục Blog ở trang chủ.

Một ví dụ code

kubectl get nodes -o wide
Mỗi ngôn ngữ nằm trong một khối data-l riêng — có thể chỉ viết một ngôn ngữ nếu muốn.
